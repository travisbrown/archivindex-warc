# pywb sample archive data

The WARC fixtures in this directory are unmodified copies of the files in
[`webrecorder/pywb/sample_archive/warcs`][pywb-data] at commit
[`9de84beead449b1ad61c756e9c031b9e6cc645e6`][pywb-commit]. They exercise the
record-reading, gzip-framing, and digest expectations used by pywb's indexing and resource-loading
tests.
