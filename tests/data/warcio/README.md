# warcio test data

The WARC fixtures in this directory are unmodified copies of the files in
[`webrecorder/warcio/test/data`][warcio-data] at commit
[`2a797aa8c6d67e70966ce9d1a690208ab250fbe7`][warcio-commit]. They are used to port the
corresponding archive-iteration and digest-checking tests from warcio.

upstream [`LICENSE`](LICENSE) and [`NOTICE`](NOTICE) files are included here with the fixtures.
The fixtures themselves have not been modified.
